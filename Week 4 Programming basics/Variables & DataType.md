## Variables in JavaScript

Variables are containers used to store data. You can use them to hold numbers, text, or boolean values.
```
let name = "Hello";     // value can change
const PI = 3.14;        // constant, cannot change
var age = 22;            // older way to declare variables
```
Real-Life Example:

Variables are like labeled jars: you can store sugar, salt, or spices in them and use them later.

## Data Types in JavaScript

JavaScript has different types of data that variables can hold:

# String – text enclosed in quotes
```
let city = "Karachi";
console.log(city); // Output: Karachi
```

# Number – numeric values
```
let age = 22;
console.log(age); // Output: 22
```

# Boolean – true or false
```
let isStudent = true;
console.log(isStudent); // Output: true
```

# Undefined – variable declared but not assigned
```
let job;
console.log(job); // Output: undefined
```

# Null – intentional absence of any value
```
let car = null;
console.log(car); // Output: null
```

# Object – collection of key-value pairs
```
let person = { name: "Fahad", age: 22 };
console.log(person.name); // Output: Fahad
```

# Array – list of values
```
let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[1]); // Output: Banana
```
# Real-Life Example:

- String = a name tag
- Number = your age
- Boolean = light switch (on/off)
- Array = a shopping list
- Object = your ID card with multiple details
