## Section B: Short Answer Questions

**1. Explain the difference between hardware and software with two examples of each.**

<details><summary>Sample Answer</summary>

**Hardware** is the physical part of a computer that you can touch. Examples: Monitor, Keyboard.

**Software** is the set of programs and instructions that tell the hardware what to do. Examples: Windows Operating System, Google Chrome Browser.
</details>

---

**2. What is the difference between a static website and a dynamic website?**

<details><summary>Sample Answer</summary>

A **static website** shows the same content to every visitor. It is built with HTML and CSS only. Example: A personal portfolio page.

A **dynamic website** shows different content based on the user, time, or data. It uses a database and server-side logic. Example: YouTube — every user sees different recommendations.
</details>

---

**3. Describe the steps that happen when you type `www.google.com` in your browser and press Enter.**

<details><summary>Sample Answer</summary>

1. The browser sends a request to the DNS server asking for the IP address of google.com
2. The DNS server returns the IP address (e.g., 142.250.190.46)
3. The browser sends an HTTP request to that IP address
4. Google's server processes the request and sends back the HTML, CSS, and JavaScript
5. The browser renders (displays) the website on your screen
</details>

---

**4. What are the three main technologies used to build the frontend of a website? Explain each in one sentence.**

<details><summary>Sample Answer</summary>

1. **HTML** — Defines the structure and content of the webpage (headings, paragraphs, images)
2. **CSS** — Controls the styling and visual appearance (colors, fonts, layout)
3. **JavaScript** — Adds interactivity and dynamic behavior (buttons, animations, form validation)
</details>

---

**5. Why is JavaScript a good choice for web development? Give at least three reasons.**

<details><summary>Sample Answer</summary>

1. JavaScript works on both frontend (browser) and backend (Node.js), so one language covers the full stack
2. It is the most popular programming language in the world with a huge community
3. It is the foundation of the MERN stack (MongoDB, Express, React, Node.js) which is widely used in industry
4. It has a rich ecosystem of libraries and frameworks that speed up development
</details>

---

**6. What is the difference between a frontend developer and a backend developer?**

<details><summary>Sample Answer</summary>

A **frontend developer** builds the part of the website that users see and interact with — the layout, design, buttons, and animations. They use HTML, CSS, JavaScript, and frameworks like React.

A **backend developer** builds the part that runs on the server — handling data, business logic, authentication, and database operations. They use Node.js, Express, and databases like MongoDB.
</details>

---

**7. Why should someone learn to code instead of using drag-and-drop website builders like Wix?**

<details><summary>Sample Answer</summary>

1. **Customization:** Code gives unlimited control over design and functionality, while builders have limited templates
2. **Performance:** Custom code runs faster because it has no unnecessary bloated code
3. **Complex Features:** Builders cannot create features like user login, real-time chat, or custom databases
4. **Career:** Coding skills lead to high-paying jobs, while knowing Wix alone does not
5. **Ownership:** With custom code, you own everything and are not dependent on a platform
</details>
