# MERN Stack Web Development — 10-Month Complete Course

A **40-week structured MERN stack course** designed for absolute beginners with zero prior knowledge. This course takes students from understanding what a computer is to building and deploying full-stack web applications.

> **For Teachers:** Use the notes and diagrams during class sessions.  
> **For Students:** Use the notes, examples, and practice questions for self-study and revision.

---

## Course Overview

| Phase | Weeks | Topic | Duration |
|-------|-------|-------|----------|
| Foundation | Week 0 | Basic Computing | 1 Week |
| Frontend | Weeks 1–4 | HTML | 4 Weeks |
| Frontend | Weeks 5–8 | CSS | 4 Weeks |
| Programming | Weeks 9–12 | JavaScript | 4 Weeks |
| Tools | Week 13 | Git & GitHub | 1 Week |

**Total: 41 Weeks (~10 Months)**

## Detailed Weekly Breakdown

### Phase 1 — Foundation

#### Week 0: Basic Computing
- What is a computer and how does it work?
- Hardware vs Software
- What is a network and the internet?
- What is a website and how does it work?
- Types of websites (Static vs Dynamic)
- History of the internet — why was it invented?
- What is programming and why do we learn it?
- Types of programming languages
- Why not just drag-and-drop website builders?
- Career paths in web development

---

### Phase 2 — HTML (Weeks 1–4)

#### Week 1: Introduction to HTML
- What is HTML and why is it important?
- How browsers render HTML
- HTML document structure (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- Headings, Paragraphs, Line Breaks
- Text formatting tags (`<b>`, `<i>`, `<u>`, `<strong>`, `<em>`)

#### Week 2: HTML Links, Images & Lists
- Hyperlinks (`<a>` tag) — internal, external, email links
- Images (`<img>` tag) — attributes, alt text, responsive images
- Ordered and Unordered Lists
- Nested Lists
- HTML comments

#### Week 3: HTML Tables & Forms
- Creating tables (`<table>`, `<tr>`, `<td>`, `<th>`)
- Table attributes — colspan, rowspan
- Form elements — `<input>`, `<textarea>`, `<select>`, `<button>`
- Input types — text, email, password, radio, checkbox, date
- Form validation — required, pattern, min/max

#### Week 4: Semantic HTML & HTML5 Features
- Semantic tags — `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Audio and Video embedding
- `<iframe>` — embedding maps and external content
- HTML5 APIs overview
- **Project:** Build a complete multi-page website

---

### Phase 3 — CSS (Weeks 5–8)

#### Week 5: Introduction to CSS
- What is CSS and why do we need it?
- Three ways to apply CSS (Inline, Internal, External)
- CSS Selectors (Element, Class, ID, Universal)
- Colors, Backgrounds, and Gradients
- Typography — fonts, sizes, weight, line-height

#### Week 6: CSS Box Model & Layout
- The Box Model — margin, padding, border, content
- Display property — block, inline, inline-block, none
- Positioning — static, relative, absolute, fixed, sticky
- Float and Clear
- Overflow property

#### Week 7: CSS Flexbox & Grid
- Flexbox — container and item properties
- Building layouts with Flexbox
- CSS Grid — rows, columns, areas
- Building layouts with Grid
- When to use Flexbox vs Grid

#### Week 8: Responsive Design & Animations
- Media Queries — breakpoints for mobile, tablet, desktop
- Mobile-first vs Desktop-first approach
- CSS Transitions and Animations
- Keyframes and transform property
- **Project:** Build a fully responsive portfolio page

---

### Phase 4 — JavaScript (Weeks 9–12)

#### Week 9: JavaScript Fundamentals
- What is JavaScript and why is it essential?
- Variables — `var`, `let`, `const`
- Data Types — string, number, boolean, null, undefined
- Operators — arithmetic, comparison, logical, assignment
- Type conversion and coercion

#### Week 10: Control Flow & Loops
- Conditional statements — `if`, `else if`, `else`
- Switch statements
- Ternary operator
- Loops — `for`, `while`, `do...while`
- `break` and `continue`

#### Week 11: Functions & Arrays
- Function declaration vs expression
- Arrow functions
- Parameters, arguments, return values
- Scope — global, local, block
- Arrays — methods (`push`, `pop`, `shift`, `map`, `filter`, `reduce`)

#### Week 12: Objects, DOM & Events
- Objects — creation, access, methods
- JSON — structure and parsing
- DOM Manipulation — selecting, creating, modifying elements
- Event handling — click, submit, keydown, mouseover
- **Project:** Build an interactive To-Do App

---

### Phase 5 — Git & GitHub (Week 13)

#### Week 13: Version Control with Git & GitHub
- What is version control and why is it important?
- Installing and configuring Git
- Basic commands — `init`, `add`, `commit`, `status`, `log`
- Branching and merging
- GitHub — creating repos, push, pull, clone
- Pull requests and collaboration
- `.gitignore` and best practices

---

### Phase 6 — Tailwind CSS (Weeks 14–15)

#### Week 14: Tailwind CSS Basics
- What is Tailwind CSS and utility-first approach
- Installation and setup
- Core utilities — spacing, typography, colors, backgrounds
- Flexbox and Grid utilities
- Responsive design with Tailwind breakpoints

#### Week 15: Tailwind CSS Components & Project
- Building components — Navbar, Cards, Buttons, Forms
- Customizing Tailwind configuration
- Dark mode support
- **Project:** Build a responsive landing page with Tailwind

---

### Phase 7 — React.js (Weeks 16–21)

#### Week 16: Introduction to React
- What is React and why use it?
- Single Page Applications (SPA) concept
- Setting up with Vite
- JSX — syntax and rules
- Components — functional components

#### Week 17: Props & Component Communication
- Props — passing data to components
- Props destructuring
- Children props
- Component composition
- Reusable component patterns

#### Week 18: State Management
- `useState` hook
- Handling forms and user input
- Controlled vs Uncontrolled components
- Lifting state up
- Conditional rendering

#### Week 19: Side Effects & Lifecycle
- `useEffect` hook
- Fetching data from APIs
- Loading and error states
- Cleanup functions
- `useRef` hook

#### Week 20: React Router & Navigation
- Installing React Router
- Routes, Links, and NavLinks
- Dynamic routes and URL parameters
- Nested routes
- Protected routes (basic)

#### Week 21: React Project
- `useContext` for global state
- Custom hooks
- Performance basics — `React.memo`
- **Project:** Build a multi-page React application (Blog or E-commerce UI)

---

### Phase 8 — Node.js & Express.js (Weeks 22–27)

#### Week 22: Introduction to Node.js
- What is Node.js and how is it different from browser JS?
- Installing Node.js and npm
- Node.js modules — `fs`, `path`, `os`
- CommonJS vs ES Modules
- Creating a simple server with `http` module

#### Week 23: npm & Modules Deep Dive
- What is npm and `package.json`
- Installing and managing packages
- Creating custom modules
- Environment variables with `dotenv`
- Nodemon for development

#### Week 24: Introduction to Express.js
- What is Express.js and why use it?
- Setting up an Express server
- Routing — GET, POST, PUT, DELETE
- Request and Response objects
- Serving static files

#### Week 25: Middleware & REST APIs
- What is middleware and how it works
- Built-in middleware — `express.json()`, `express.static()`
- Custom middleware
- RESTful API design principles
- Status codes and error handling

#### Week 26: CRUD Operations & Validation
- Building a complete CRUD API
- Request validation with Joi or express-validator
- Error handling middleware
- File uploads with Multer
- API testing with Postman or Thunder Client

#### Week 27: Authentication & Security
- What is authentication vs authorization?
- Password hashing with bcrypt
- JSON Web Tokens (JWT)
- Login and registration system
- **Project:** Build a complete REST API with authentication

---

### Phase 9 — MongoDB & Mongoose (Weeks 28–31)

#### Week 28: Introduction to MongoDB
- What is MongoDB and NoSQL databases?
- SQL vs NoSQL comparison
- Installing MongoDB and MongoDB Compass
- MongoDB Atlas — cloud database setup
- CRUD operations in MongoDB Shell

#### Week 29: Mongoose ODM
- What is Mongoose and why use it?
- Connecting to MongoDB with Mongoose
- Schemas and Models
- Data types and validation
- CRUD operations with Mongoose

#### Week 30: Advanced Queries & Relations
- Query operators — `$gt`, `$lt`, `$in`, `$regex`
- Sorting, pagination, and filtering
- Population — referencing documents
- Virtuals and instance methods
- Indexing for performance

#### Week 31: MongoDB with Express Integration
- Connecting MongoDB to Express API
- Environment-based configuration
- Data seeding
- Aggregation pipeline basics
- **Project:** Full CRUD API with MongoDB backend

---

### Phase 10 — Full Stack MERN Projects (Weeks 32–36)

#### Week 32: MERN Stack Integration
- Connecting React frontend to Express backend
- CORS configuration
- Proxy setup
- API calls from React with Axios or Fetch
- Folder structure for full-stack projects

#### Week 33: Authentication in MERN
- User registration and login flow
- JWT token storage (cookies vs localStorage)
- Protected routes in React
- Auth context and state management
- Role-based access control

#### Week 34: Advanced Features
- Image and file upload (frontend + backend)
- Search, filter, and pagination
- Real-time features with Socket.io (introduction)
- Email notifications (Nodemailer basics)
- Payment integration overview

#### Week 35: MERN Project — Part 1
- Project planning and database design
- Setting up the backend — models, routes, controllers
- Building the frontend — pages, components, routing
- Connecting frontend to backend

#### Week 36: MERN Project — Part 2
- Adding authentication
- Implementing all CRUD features
- Styling and responsive design
- Testing and bug fixing
- **Project:** Complete MERN application (Blog Platform or Task Manager)

---

### Phase 11 — Deployment & Final Project (Weeks 37–40)

#### Week 37: Deployment Fundamentals
- What is deployment and hosting?
- Domain names and DNS basics
- Frontend deployment — Vercel, Netlify
- Backend deployment — Render, Railway
- Environment variables in production

#### Week 38: Advanced Deployment & DevOps Basics
- MongoDB Atlas for production
- CI/CD basics — GitHub Actions
- Docker introduction (overview only)
- SSL and HTTPS
- Performance monitoring

#### Week 39: Final Project — Part 1
- Project planning and wireframing
- Database schema design
- Building the backend API
- Building the React frontend
- Integrating all features

#### Week 40: Final Project — Part 2
- Final testing and bug fixing
- Deployment to production
- Building a developer portfolio
- Resume and LinkedIn tips for developers
- **Final Project:** Full-stack MERN portfolio website with blog
